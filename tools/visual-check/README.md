# visual-check

Сравнивает макеты из `PAGES/` с реальными страницами приложения: для каждой пары снимает
скриншоты `mockup-<имя>.png` и `page-<имя>.png` в окне 1280x900, считает процент отличающихся
пикселей и проверяет структуру (классы, размеры, шрифт Manrope, активный пункт меню, остатки
заглушек `[...]`, Bootstrap).

Текст в макетах состоит из заглушек, поэтому часть пикселей отличается всегда. Смотрите на список
структурных замечаний в `out/report.html`, а процент используйте как грубый ориентир.

## Запуск

```bash
cd tools/visual-check
npm install
npx playwright install chromium
# приложение должно работать (по умолчанию http://localhost:8080) в режиме Development с демо-данными
npm run check
```

Переменные окружения: `BASE_URL`, `MOCKUPS_DIR`, `OUT_DIR`, `ADMIN_EMAIL`, `ADMIN_PASSWORD`.
`npm run self-test` сравнивает каждый макет с самим собой (проверка самого скрипта, ожидается 0%).
`node run.mjs --only=panel-1-bookings,public-1-home` прогоняет выбранные пары.
